EDUAGENDAFÁCIL

Projeto com versão web (Flask) e versão desktop (Tkinter), compartilhando o arquivo tarefas.json.

REQUISITOS
- Python 3.9 ou superior
- Flask para a versão web

INSTALAÇÃO
1. Extraia a pasta EduAgendaFacil.
2. Abra o terminal dentro da pasta.
3. Instale as dependências:
   pip install -r requirements.txt

EXECUTAR A VERSÃO WEB
   python app.py
Depois abra no navegador:
   http://127.0.0.1:5000

EXECUTAR A VERSÃO DESKTOP
   python desktop.py

OBSERVAÇÕES
- Os dados ficam salvos em tarefas.json.
- Para compartilhar os mesmos dados entre as versões, execute os programas a partir desta mesma pasta.
- A versão web está configurada para uso local. Não publique em servidor sem configurar segurança, chave secreta e proteção adequada.
